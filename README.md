# GlassTB

GlassTB es un fork de [TranslucentTB](https://github.com/TranslucentTB/TranslucentTB). Permite personalizar la transparencia y el color de la barra de tareas en Windows 10 y Windows 11. Conserva los modos de apariencia del proyecto original y puede aplicar distintos ajustes cuando hay una ventana maximizada o se abre Inicio, Búsqueda o Vista de tareas.

El ejecutable se llama `GlassTB.exe`. La edición portable requiere Windows 11. GlassTB y TranslucentTB pueden instalarse en el mismo equipo. Si ambos están abiertos, las dos aplicaciones pueden aplicar cambios a la misma barra de tareas. Usa solo una a la vez.
